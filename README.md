# 大專比賽情報

這是一個公開的靜態網頁，用來整理仍開放或即將開放、大專（副學位／學士／研究生）可參加，並且與科學／STEM／創科／教學設計相關的公開比賽。

資料來自例行掃描時成功讀到的官頁、官方 API 或主辦／政府通告原文。本站不是政府、大學或各比賽的官方網頁；名稱、截止、對象與連結請以各官頁為準。官頁未列鐘點或時區者，本站不會補上推測時區。約合香港時間若為換算，會另行標明。官方資料衝突、未能確認香港學生可報，或不把新報名視為仍開的項目，會放在「待確認／暫不列入」，不當作已確定開放。

## 如何更新

網站檔案在 `docs/`。推送到 `main` 後，GitHub Actions 會用官方 Pages 動作把 `docs/` 發佈為 GitHub Pages（不會把 `.github` 目錄一併公開）。也可在 Actions 頁手動執行工作流程。
